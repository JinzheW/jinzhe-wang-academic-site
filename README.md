# Jinzhe Wang — Academic Website

Source files for the personal academic website of Jinzhe Wang (王今者).

## Edit content

Open `index.html` in GitHub and use the pencil button. The main editable areas are
marked with `EDIT POINT` comments. This file contains the introduction, email, CV link,
working-paper titles, coauthor links, paper links, and abstracts.

## Edit appearance

Open `styles.css` to change typography, colors, spacing, image size, and responsive layout.

## Replace the portrait

Upload a new file to `images/portrait.jpg` using the same filename.

## Structure

- `index.html` — page content
- `styles.css` — visual design
- `script.js` — optional debug overlay
- `images/portrait.jpg` — homepage portrait
